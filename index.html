SDC-1

Biometric access controller — fingerprint, face, NFC.

Your browser cannot flash devices. Use desktop Chrome or Edge. This page must be served over HTTPS.

Plug the SDC-1 into this computer by USB, then press the button. Wi-Fi setup is offered straight after flashing.

Then, in Home Assistant

  1. Home Assistant discovers the device automatically and offers to add it. Accept, and the encryption key is generated and stored for you.
  2. Install the dashboard card: HACS → three dots → Custom repositories → deanex-international/sdc-1, category Dashboard.
  3. Add the card to a dashboard: Add card → SDC-1 Access Control.

Firmware updates arrive by themselves — the device checks for new releases and Home Assistant shows an Update entity when one is available.
